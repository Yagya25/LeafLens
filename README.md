# LeafLens

Leaf Spot Detection and Affected-Area Estimation

This course prototype combines colour conversion, filtering, segmentation and morphology with connected-component detection. It identifies brown/dark-yellow candidate spots on a single green leaf photographed against a plain white/grey background. It does not identify a disease or prescribe treatment.

## Run

Install Python 3.10 or later, open a terminal in this folder, and run:

```bash
python -m pip install -r requirements.txt
python leaflens.py samples/five_spots.png --out results/my_demo
```

To use a photo:

```bash
python leaflens.py "my_leaf.jpg" --out results/my_leaf
```

Take a sharp image of one green leaf on matte white paper in even daylight. Keep the whole leaf inside the frame. Avoid hands, coloured backgrounds, overlapping leaves, strong shadows and reflections. Very brown leaves are outside the intended scope. Inspect the masks before trusting the area estimate.

The program saves input.png, leaf_mask.png, spot_mask.png, annotated.png and result.json. Box coordinates refer to the resized working image. A null affected_percent means no usable leaf region; it does not mean a healthy leaf.

## Demonstration and limits

All supplied sample images are computer-drawn synthetic illustrations, not field photographs. Results included here were generated by running the code on these images. They test basic pipeline behaviour only. No real-leaf accuracy, disease recognition or field validation is claimed.

HSV thresholds and kernel sizes are documented in the report. They are baseline settings, not universal values. Change them using a separate development set, then freeze them before testing. The minimum component size is 20 working-image pixels; tiny spots may be removed, touching spots may merge, and natural brown regions may be false positives. The algorithm fills the outer leaf contour, so leaf holes can bias its area estimate.

## Explain in a viva

- Processing: Gaussian smoothing, BGR-to-HSV conversion, thresholding and morphological cleanup.
- Detection: label connected candidate regions and draw a box around each retained component.
- Measurement: affected area = retained spot pixels / leaf-mask pixels x 100.
- A bounding box localises a spot; its rectangular area is not used to measure the spot.
- No trained model or GPU is required for this baseline.
- No detected spot is not the same as a confirmed healthy leaf.
